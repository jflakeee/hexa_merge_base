# 애니메이션 리서치 후 구현·시각 검증

2026-10-05 · 로컬 개발 서버 검증 후 운영 배포 완료. [배포 검증](../deployment/review.md).

## 적용한 내용

- 적 피격 플래시(65ms)·시각 반동(120ms). 이벤트에 대상 ID와 방향을 추가했다. 충돌 판정 좌표는 변경하지 않는다. 정예 적은 피격 뒤 원래 색상으로 복원한다.
- 플레이어 체력의 지연 표시. 실제 체력 바와 별도로 피해 흔적을 150ms 유지한 뒤 감소시키며 연속 피해·회복을 처리한다.
- 일반 탐험·전투의 적 처치 잔상(200ms). 판정에서 제거된 적과 표시의 수명을 분리했다.
- 버튼 눌림·결과 모달 등장, 골드 카운트업(280ms), 획득 위치에서 HUD로 이동하는 보상 표시(420ms).
- 성공 시 처치 인식 후 결과 표시(420ms). 결과 보기로 건너뛰기 가능. 보상은 지연 전에 저장하며 반복 종료 호출로 중복 지급하지 않는다. 보스 처치 시 체력바를 0으로 표시한다.
- 화면 움직임 설정과 운영체제 동작 감소 설정 연결. 카메라 흔들림·상하 흔들림·배경 이동·문자 이동·처치 축소·보상 이동을 줄인다. 필수 피해 정보는 유지한다. 무적 표시는 빠른 점멸에서 반투명으로 변경했다.
- 피해 문자 24개, 보상 이동 5개, 효과음 동시 6개 제한. 같은 효과음 60ms 내 반복을 억제하고 장면 종료 때 보상 DOM 효과를 정리한다.

구현: `src/systems/presentation.js`, `CombatScene.js`, `IdleScene.js`, `art.js`, `main.js`, `style.css`, `audio.js`, 설정 UI·상태, 전투 이벤트.

짧은 효과를 자동화 지연 때문에 놓치지 않도록 전투 장면을 일시 정지하고 정해진 업데이트로 피격·처치 스크린샷을 촬영했다. 보스 결과 전환은 장면을 다시 진행해 확인했다. 녹화에는 이러한 제어 구간이 포함되므로 실시간 타격감이나 FPS 측정 결과로 해석하면 안 된다.

초기 검증 중 탭 접근성 이름의 아이콘, 타이밍에 의존한 체력바 캡처, 자동 전투가 진행된 상태의 처치 수 비교가 실패했다. 선택자와 고정 전투 시나리오를 수정한 뒤 최종 검증을 통과했다. 새 motion 기본값에 맞춰 기존 상태 테스트 기대값도 갱신했다.

## 범위와 남은 선택 항목

이번 작업은 리서치의 기본 피드백과 처치·보상 연결을 적용한 것이다. 영상의 30개 효과를 모두 구현했다는 의미는 아니다. 전역 히트스톱·슬로모션·카메라 확대·프레임 기반 걷기 아트는 추가하지 않았다. 실제 모바일 장치 성능, 10분 부하, 운영 사이트·포털 iframe은 이번 로컬 검증 범위에 포함하지 않는다.
