# 재설계 대비 미구현 작업 검토

검토일: 2026-10-06. 기준 문서: [재설계 가능성 분석](../../research/project-application/redesign-feasibility.md), [16개 적용 로드맵](../../research/project-application/roadmap.md). 코드와 최신 자동화 화면/동작 결과, 배포 기록을 대조했다.

후속 구현 갱신: 위험 기하 공통화/F2 오버레이, 적 프레임, 결과 장비 비교, 저장 복원, 탐험 원경 시차, 경고 우선순위와 동급 경고 합산, 보스별 입장음/이름, 첫 장비 안내가 추가됐다. 보상 경로/기대 횟수 계산도 별도 분석 문서로 정리했다. 아래 표는 최신 로컬 코드와 Playwright 결과를 반영한다.

## 판정

권장 B안은 **대표 구간이 구현된 상태**다. 전체 재설계 완료로 볼 수는 없다. 준비·장비·전투 진입, 일부 주인공/슬라임 자세, 돌진·방사 위험 표시, 짧은 보스 소개가 있다. 여러 설계 항목은 부분 구현 또는 제안 수준에 남는다.

| 설계 항목 | 현재 상태 | 남은 차이 |
|---|---|---|
| 넓은 화면 준비·장비 구성 | 대표 구간 완료 | 결과/획득 화면까지 준비 흐름 연결은 남음. 공개 포털 iframe 실제 실행은 배포 확인 완료 |
| 전투 폭 정책 | 결정 반영 | 재설계 1차안은 판정 공간을 넓히지 않고 전투 캔버스를 최대 520px 기준으로 유지한다. 큰 화면은 좌우 준비 화면에 사용한다. 추후 전투 확대 시에만 논리 좌표 분리가 필요 |
| 장비 전후 비교·자동 장착 보호 | 구현 | 인벤토리와 전투 보상에서 시작 시점 대비 능력치/세트 변화 표시. 장기 저장 이행과 복수 보상 누적 상황의 별도 사용자 평가 기록은 남음 |
| 출전 준비·첫 성장 안내 | 부분 구현 | 빈 장비 슬롯에 감정된 물품이 있으면 비교 안내와 비교 펼침 이동을 제공하고 자동 비교를 검증. 출전까지 잇는 단계별 목표 흐름은 남음 |
| 위험 표현 | 구현 보강 | 위험 반경/돌진 폭을 규칙과 표시가 공유하고 개발 빌드 F2 판정 겹침 표시를 추가. 위협 동시 발생과 실제 모바일에서의 회피 이해도 측정은 남음 |
| 캐릭터 동작 프레임 | 구현 보강 | 주인공의 이동/준비/공격/피격, 일반 적 3종과 수호자 자세를 추가. 별도 해상도 비교 및 저사양 모바일 확인은 남음 |
| 보스 소개 | 보강 | 보스별 이름·안내·입장음·페이드와 정지 타이머, 건너뛰기, 감소 모션 제공. 시선 추적 연출은 없으며 전 기기 상태 조합 검증은 미완 |
| 배경 공간감 | 구현 보강 | 반복 벽 대비를 낮추고 원경 그래픽을 별도 레이어로 분리해 탐험에서 벽보다 느리게 이동시킴. 전투는 정지 배경 유지. 새 원경 캡처와 실제 기기 성능 확인은 필요 |
| 위험/HUD 정보 우선순위 | 구현 보강 | 보스 경고 우선, 동급 메시지 합산, status live 안내 적용. 밀집 상황의 실제 플레이 가독성 평가는 남음 |
| 애니메이션 수명/취소 | 부분 | 감소 모션, 씬 종료 정리, 일부 동시 표시 상한이 있음. 공통 표현 수명/우선순위 정책과 resize·중단·스킵 전 상태 복원 계약은 없음 |
| 재현/성능 기반 | 부분 | 고정 위험 fixture, 재현 브라우저 시나리오, 1배/4배 CPU profile을 기록. headless 실행에서 대기 약 29/25fps, 전투 약 18/17fps로 낮게 나왔으나 제한 없는 결과도 30fps 수준이라 호스트 주사율과 실제 부하를 분리하지 못함. 실제 기기 측정/프로파일링은 필요 |
| 아트 스타일 규칙 | 대표 자산 기준 문서화 | 16px 격자, 명암, 윤곽, 위험 표시 원칙을 문서화하고 캐릭터 포즈 시트를 검토. 전체 적/지역 적용은 남음 |
| 적 역할과 페이싱 | 초기 역할 구현 | 박쥐는 좌우로 흔들며 접근하고 해골은 근거리에서 거리를 둔다. 자동 포즈 비교 통과. 수치 난이도와 전투 강약/공정성은 별도 반복 플레이 평가 필요 |
| 보상 분포 모델 | 계산 분석 완료 | 등급 롤의 평균/95% 횟수, 확률 드롭 경로, 큐브 확정 합성 비용을 계산. 실제 플레이 시간/재화 공급 실측과 밸런스 조정 결정은 남음 |
| 강한 타격 정지 연출 | 미채택 | 로드맵 P3의 선택 실험. 현재 범위에서 필수 누락은 아님 |

## 우선순위 권고

1. **통과 — 결과 비교와 저장 복귀:** 실제 전투 보상 비교와 새로고침 복원을 자동 시나리오에서 확인했다. 다양한 중복 보상 조합의 사용자 평가는 선택 과제다.
2. **자동 검증 통과 — 위험 경고 우선순위:** 보스 우선 및 동급 합산과 접근성 공지를 구현했다. 실제 혼잡 전투의 플레이어 이해도 평가는 남는다.
3. **통과 — 대표 구간 레이아웃과 원경:** 데스크톱·320px·390px와 위험 레이어를 캡처로 확인했다. 이음매/감소 모션 회귀 시나리오는 계속 유지한다.
4. **부분 — 픽셀 스타일:** 대표 규칙과 캐릭터 시트는 확인했다. 전체 적·지역 자산을 같은 기준으로 정비해야 한다.
5. **미완료 — 기기 성능:** 포털 iframe은 공개 Chromium에서 통과했다. 저사양 실기기 프레임/메모리 측정이 필요하다.
6. **부분 — 첫 성장, 적 역할, 보상 분포:** 장비 첫 선택과 역할 이동, 확률/합성 모델은 구현·계산했다. 튜토리얼과 게임 내 경제 실측은 남는다.
7. **보류 — 강한 타격 정지:** P3 선택 실험으로 유지한다.

## 배포 상태 메모
