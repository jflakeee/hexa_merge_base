# 재설계 미완료 항목 후속 구현

2026-10-06. [격차 검토서](design-gap-review.md)의 최우선 차이에 대한 구현 갱신이다.

## 이번 갱신

- 폭발/돌진/적 탄환/접촉의 충돌 기하를 `hazardRules.js`에 모아 판정과 표시가 같은 값을 사용하게 했다. 개발 전투 화면은 F2로 플레이어·적·위험 판정 겹침을 표시한다.
- 적 3종과 수호자에 동작 자세를 추가했다. 기존 공격/이동/HP 규칙은 그대로 사용한다.
- 전투 보상 화면에 드롭 장비 이름, 자동 장착/가방 보관/골드 환산, 시작 당시 장비 대비 공격·방어 및 해제 세트 효과를 표시한다.
- 저장 데이터에 마지막 결과를 제한된 필드로 복원해 새로고침 후 보상 설명을 다시 볼 수 있다.
- 탐험 배경 원경을 별도 그래픽 레이어로 만들어 벽보다 느린 시차로 이동한다. reduced motion에서는 층이 함께 정지한다.
- 겹친 경고는 보스 위험 우선, 군집 경고 후순위로 처리한다. 동급 신호는 한 줄에 합친다.
- 픽셀 아트 최소 규칙을 [스타일 가이드 초안](../../research/project-application/pixel-style-guide.md)에 기록했다.
- 첫 빈 장비 슬롯에 감정된 물품이 있으면 비교 위치로 바로 이동하는 장비 안내를 추가했다.
- 박쥐는 접근 중 좌우로 흔들고 해골은 가까이 붙으면 거리를 벌려 적 역할을 시각과 움직임 양쪽에서 구분한다. 군집 우두머리와 보스는 추적/공격 규칙을 유지한다.
- 보스 소개는 실제 등장 보스 이름과 독립 사운드 신호를 사용한다. 경고 UI는 보스 위험 우선순위와 동급 합산, 보조기기용 status announcement를 제공한다.
- 등급 확률의 기대 횟수/95% 횟수, 방치·생존·상자·보스 경로, 큐브 확정 합성 비용 모델을 계산 문서로 남겼다.
- 전투 공간 정책은 첫 재설계 기준에서 최대 520px 기존 판정 폭을 유지하는 것으로 문서화했다. 전장 자체를 확대하는 변경은 이번 구현에 넣지 않았다.

## 검증

- 단위 테스트 20개 파일, 121개 통과(적 행동 역할과 첫 장비 도움말 포함).
- Playwright 모션/전투 검증 통과: 보스 소개 정지·건너뛰기, 적별 포즈, 감소 모션, F2 판정 표시, 경고 우선순위/합산, 장비 보상 비교, 저장 복귀 확인. 상세 결과는 [motion results](../2026-10-05/motion/results.json).
- Playwright 재설계 검증 통과: 첫 장비 안내와 비교 이동, 세트 상실 설명, 장비 잠금/수동 교체, 320px/390px/넓은 화면, 위험 오버레이, 축소 모션 확인. [결과](../2026-10-05/redesign/results.json).
- Pages 배포 및 공개 검증 통과: 게임 `4ef7281`, 도메인 `ae656bc`, 번들 `/claude_game/assets/index-2Rgyv_5u.js`. 데스크톱/모바일, 보스 전투/복귀, 설정 저장, 포털 iframe과 오류 0건을 확인했다. [결과와 캡처](deployment/results.json).
- 탐험 장면 능력치는 저장소 변경 때만 다시 계산하고, 캐릭터 스프라이트는 포즈가 바뀔 때만 텍스처를 교체하도록 최적화했다. Playwright frame audit 수치는 headless 실행 제한과 부하를 분리하지 못해 실제 성능 개선을 주장하지 않는다. [1배](deployment/performance-1x.json) · [4배 제한](deployment/performance-4x.json).
- 탐험 대표 화면의 원경 변경을 캡처로 확인했다. 초기 원형 고리 장식은 기존 창과 겹쳐 보였고 낮은 대비의 기둥 실루엣으로 수정한 뒤 재캡처했다.
- 최신 소스 프로덕션 빌드 성공(`dist/assets/index-2Rgyv_5u.js`, 약 1.56MB), `git diff --check` 통과. 번들 크기 경고와 코드 분할 미적용은 남아 있다.

## 계속 남는 항목

남은 외부 확인은 실제 iOS/저사양 기기 성능 측정이다. 포털 iframe 조작은 공개 Chromium 모바일 에뮬레이션에서 통과했다. 경고 우선순위 자동 시나리오는 통과했지만 밀집 전투의 실제 플레이 가독성 사용자 평가는 없다. 첫 빈 장비 슬롯 안내는 구현했으나 장기 목표 튜토리얼은 남았다. 적의 이동 역할은 구분했지만 난이도/공정성 플레이 평가와 실제 플레이 시간 기반 보상 밸런싱은 남았다. 픽셀 규칙은 문서화하고 대표 캐릭터 포즈를 검토했으나 모든 적·지역 자산의 스타일 통일은 완료하지 않았다.
