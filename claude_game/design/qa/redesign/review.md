# 시각 경험 재설계 — 첫 대표 구간 검증

2026-10-05. Phaser + DOM과 기존 성장·저장 구조를 유지하는 권장 B안을 구현했다. 전체 재설계 완료가 아니라 탐험 준비 → 장비 선택 → 전투 진입 구간의 구현 결과다. 이번 변경은 로컬에서 검증했으며 배포하지 않았다.

## 구현

- 데스크톱 탐험 화면을 최대 1180px로 확장하고 장비 패널을 오른쪽 390px에 배치했다. 전투는 기존 최대 520px 영역을 유지한다.
- 생존 전투와 보스 출전 버튼을 명시적으로 제공한다. 배경 탭으로 전투에 진입하지 않는다.
- 장비 교체 전후 실효 능력치와 해제되는 세트·룬워드 효과를 표시한다. 장비 유지 설정은 자동 교체를 차단하고 저장되며, 수동 교체는 허용한다.
- 돌진 경로는 폭과 방향 화살표로, 방사 공격은 방사형 선으로 구분한다. 피해 계산과 공격 타이밍은 변경하지 않았다.
- 탐험 배경의 벽 대비를 낮추고 큰 아치 창을 추가했다. 전투 바닥 장식의 대비를 낮춰 위험 표시의 식별을 돕는다.
- 장비 비교 펼침과 키보드 포커스를 상태 갱신 시 복원한다.

## 검증 결과

- 단위 테스트: 20개 파일, 121개 테스트 통과.
- 프로덕션 빌드 성공. 기존 대형 번들 경고는 남아 있다.
- `git diff --check` 통과.
- Playwright `tests/visual-redesign.cjs` 통과, 페이지 오류 0개. [기계 판정 결과](results.json).
- 1280×900, 390×844, 320×568에서 캡처 검토. 넓은 화면과 소형 모바일에서 가로 넘침 없음. 320px 화면에서도 캐릭터 하단이 출전 버튼 영역 위에 위치한다.
- 세트 해제 시 공격 31→27, 방어 26→21을 비교 화면에 반영한다. 유지 설정의 새로고침 후 복원과 유지 장비의 수동 교체를 확인했다.
- 탐험→생존/보스→결과→탐험 복귀, 데스크톱 전투 폭 유지, reduced-motion 설정 상태의 진입·복귀를 확인했다.

위험 표시 캡처는 고정 배치 후 장면을 정지한 검증용 fixture다. 이 결과로 실제 플레이 중 회피 성공률이나 프레임 성능 개선까지 입증한 것은 아니다. 기존 날짜별 시각 감사 스크립트에는 과거 캔버스 탭 진입 방식이 남아 있으므로 이번 흐름의 재검증에는 새 스크립트를 사용한다. 로컬 서버는 포트 5174가 필요하다.

## 후속 범위

캐릭터 동작 프레임, 다층 배경 움직임, 카메라 연출, 전체 콘텐츠의 표현 통일은 남아 있다. 대표 구간의 실제 플레이 평가와 성능 측정도 별도 진행이 필요하다. 자세한 단계는 [재설계 가능성 분석](../../../research/project-application/redesign-feasibility.md)을 따른다.
