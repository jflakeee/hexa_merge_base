# 행동 프레임·보스 입장 연출 검증

2026-10-05. 재설계 대표 구간의 후속 구현. 로컬 검증이며 배포 전이다.

- 주인공: 이동 2프레임, 공격 준비, 공격, 피격 자세 추가. 탐험과 전투에 적용했다.
- 슬라임: 이동과 피격 자세 추가. 다른 적의 프레임 확장은 남아 있다.
- 표현 텍스처만 교체하며 피해·이동 좌표와 공격 주기는 기존 규칙을 따른다.
- 보스 입장: 0.9초 안내와 450ms 카메라 페이드. 입장 중 규칙 갱신과 전투 타이머를 멈춘다. 바로 시작 버튼으로 건너뛸 수 있다.
- 모션 감소: 추가 동작 프레임과 입장 연출을 생략한다.

## 검증

단위 테스트 121개 통과. 프로덕션 빌드 성공(기존 대형 번들 경고 유지). `tests/visual-redesign.cjs` 회귀 검증 통과. `tests/visual-motion.cjs`에서 타이머 정지, 건너뛰기 후 진행, 실제 이동 프레임 전환, 모션 감소의 정적 자세와 입장 생략을 확인했다. [자동 검증 결과](results.json).

브라우저 검증 과정에서 생성 시 장면 시계와 갱신 시 게임 시계의 기준 차이로 소개가 즉시 끝나는 문제를 발견해 수정했다. [입장 화면](01-introduction.png)을 직접 검토한 뒤 안내가 보스를 가리지 않도록 위치를 조정했다. [자세 비교 화면](02-poses.png)은 생성된 텍스처를 실제 브라우저에서 확대 표시한 검토용 화면이다.

검증은 데스크톱 Chromium의 모바일 뷰포트에서 수행했다. 입장 정지 검증을 위해 테스트에서만 연출 시간을 연장했다. 실제 기기 성능이나 사용자 이해 개선을 측정한 결과는 아니다. 박쥐·해골·수호자의 행동 프레임, 다층 배경, 전체 콘텐츠 확장은 후속 범위다.

2026-10-06 갱신: 일반 적 3종/수호자 자세, 위험 판정 디버그, 결과 화면 장비 비교와 저장 복원을 추가했다. 최신 캡처와 자동 판정은 [2026-10-05/motion/results.json](results.json)과 `03-hitboxes.png`, `04-reward-comparison.png`에 반영되어 있다. 실제 기기 성능·시각 이해도 평가는 계속 남아 있다.
