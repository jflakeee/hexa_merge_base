설계와 리서치

게임 시각 경험 개선을 위한 조사, 프로젝트 적용 설계, 구현 점검과 배포 검증 자료를 주제별로 모았습니다. 문서와 원본 분석 자료는 아래 링크에서 확인할 수 있습니다.

게임 개발 및 시각 경험 리서치

  • 리서치 전체 안내모든 연구 분야의 문서와 적용 자료
  • 영상 기반 애니메이션 효과 분석참고 영상 분석과 게임 구현 아이디어
  • 30가지 이후 애니메이션 효과 조사효과 카탈로그 및 구현 제안
  • 시네마틱, 카메라와 카툰 렌더링촬영·화면 전환·렌더링 기법
  • 게임 개발 이론시스템 설계, 밸런스와 검증
  • 시각 경험 개선 방법론측정·실험·평가 절차
  • 현재 프로젝트 적용 분석현황 분석, 재설계 검토와 적용 로드맵
  • 모바일 UX 전면 재설계 검토기존 설계문서 전수 대조와 모바일 과업 중심 권고안
  • 모바일 UX 통합 제안화면 구조, 전투 흐름, 터치 조작 우선순위

기준 설계와 실행 계획

  • 초기 게임 설계원래 모바일 레이아웃과 핵심 게임 루프
  • 확장 시스템 설계장비, 제작, 스킬, 보스와 거래 규칙
  • 초기 구현 계획기능 작업 순서와 완료 조건
  • 수정 및 안정화 계획저장, 진행, 성장 시스템 후속 작업

구현 및 시각 검증

  • 최신 공개 배포 검증성장 안내 배포 빌드와 게임 포털 iframe 재확인
  • 설계 대비 구현 격차 검토완료 항목과 후속 작업
  • 구현 진행 기록재설계 구현 상태
  • 원격 배포 시각 검증데스크톱·모바일·보스·게임 포털 확인
  • 전투 화면 재설계 검증레이아웃과 전투 가독성 점검
  • 게임 모션 검증포즈, 히트박스와 보상 피드백
  • 화면 표현 검증피격, 체력 표시, 결과 화면 및 모션 설정
  • 이전 배포 검증 기록공개 빌드와 포털 연결 확인
  • 첫 성장 안내 검증장비 획득부터 첫 전투까지 브라우저 시나리오
