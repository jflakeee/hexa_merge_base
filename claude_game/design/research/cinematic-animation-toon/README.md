# 화면 전환·카메라·촬영·카툰 렌더링 조사

조사일: 2026-10-05 · 적용 대상: Phaser 3.90 기반 2D 픽셀 게임

화면 전환/편집 12개, 카메라 12개, 촬영/구도 12개, 카툰/NPR 12개를 **48개 연구 항목**으로 정리했다. 이는 서로 독립적인 신규 효과 48종이라는 뜻이 아니다. 랙 포커스는 카메라 항목이지만 실제 카메라 이동이 아니며, 추적 촬영은 다른 이동 방식과 조합된다. 기존 30종 및 추가 24개 조사와 겹치는 항목도 있다.

- [카툰/NPR 12개: 제작 방법과 제약](toon-rendering.md)
- [게임 적용 설계: 우선순위·보스 등장 콘티·검증 기준](game-application.md)

Columbia 영화 용어집, ARRI 촬영/조명 자료, Adobe 편집 문서, Disney 원문 논문, Sony Pictures Imageworks 제작 설명, Blender·Unity·VRM·Phaser 공식 문서를 조사했다. 아래 문서에서 **원리와 출처**, **이 프로젝트에 대한 제안**을 구분한다. 오래된 논문·버전 문서는 기법의 원리 참고이며 최신 제품 지원을 보장하지 않는다.

이번 결과는 연구 문서다. 새 효과를 구현하거나 운영 사이트에 배포하지 않았고, 성능·시각 품질 측정 결과를 주장하지 않는다. 전체 영화 촬영 기법을 망라한 백과사전은 아니며 게임 적용성이 높은 항목을 선정했다.
