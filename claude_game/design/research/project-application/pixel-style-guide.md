# Starlight Labyrinth 픽셀 표현 기준 초안

재설계 대표 아트에 적용할 최소 기준. 실제 표시 크기에서 읽히는지를 먼저 판단한다.

## 형태와 픽셀

- 원본 캐릭터 타일은 16×16 정수 픽셀 격자에 맞춘다. 표시 확대는 정수배를 우선하고 픽셀 보간을 끈다.
- 일반 캐릭터 실루엣은 배경과 명도 차이를 확보하고, 주인공 외곽은 따뜻한 살구/주홍 계열로 유지한다. 수호자·저주 계열은 자주색을 쓰되 위험 원의 색만으로 역할을 전달하지 않는다.
- 주요 재질은 어두운 외곽, 기본색, 밝은 면의 3단계를 기준으로 하며 눈·무기·핵심 룬에는 작은 하이라이트를 허용한다.
- 그림자와 접지 기준은 발 아래에 둔다. 애니메이션 프레임 사이 몸통 중심은 크게 흔들지 말고, 이동은 발·날개·하단 윤곽 변화로 읽히게 한다.

## 위험 표시

- 예고와 활성 상태는 모양과 외곽선 강도로 모두 구분한다.
- 폭발은 원형 면적, 돌진은 실제 판정 반폭과 일치하는 통로, 방사 공격은 발사원과 탄의 방향을 사용한다.
- 색상은 정보의 보조 수단이다. 플레이어·적·판정선 외곽을 분리하고, 효과가 겹칠 때 캐릭터와 이동 통로가 가려지지 않게 한다.
- F2 개발 표시를 켜서 충돌 반경을 비교할 수 있게 유지한다.

## 화면 검토

아트는 원본 픽셀 크기와 실제 표시 배율 둘 다 확인한다. 320px, 390px, 넓은 화면에서 캐릭터, HP, 경고, 길이 읽히는지 캡처로 비교한다. 장식 대비를 높여 캐릭터/위험보다 먼저 보이게 만들지 않는다.

이 기준은 대표 구간에 대한 초안이다. 나머지 몬스터와 지역을 모두 갱신하고 실제 저사양 기기에서 확인하기 전에는 전 프로젝트의 스타일 일관성을 완료로 판정하지 않는다.
