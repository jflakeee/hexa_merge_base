# 전체 리서치의 현재 프로젝트 적용 분석

분석일: 2026-10-05 · 범위: 기존 영상 30종, 추가 효과 24개/변형 8개/구현 기법 6개, 촬영·카툰 48항목, 게임 개발 이론, 시각 경험 방법론 16개.

## 결론

현재 게임에는 피격·체력·처치·보상·기본 UI 피드백이 이미 있다. 다음 단계는 **정보를 정확히 읽게 만들고 장비 선택의 결과를 설명한 뒤**, 작은 프레임 아트·시차·보스 소개로 표현을 확장하는 것이 적합하다. 모든 연구 항목을 기능으로 추가하는 방식은 권장하지 않는다.

## 가장 먼저 검토할 요소

| 우선 | 요소 | 현재 프로젝트에 필요한 이유 |
|---|---|---|
| P0 | 위험·저주·오라의 형태와 판정 표현 | 원형 효과가 여러 의미를 가지며 돌진은 표시/접촉 범위의 관계를 명시할 필요가 있음 |
| P0 | 자동 장착의 전후 비교와 빌드 보호 | 실제 함수 실행에서 합계가 높은 장비로 교체하며 세트 보너스를 잃는 사례 확인 |
| P0 | 모션·섬광·연출 수명 정책 | 효과별 설정 적용 범위와 향후 카메라/보상 좌표 연결을 통일 |
| P1 | 배경 대비·실루엣·체력 정보 | 이미 있는 피드백의 인식과 가독성을 개선하는 실험 |
| P1 | 장착 위치 연결·첫 성장 안내 | 장비가 왜 바뀌었고 어떤 효과가 생겼는지 학습 지원 |
| P1 | 핵심 동작 프레임과 선택적 효과 | 상하 흔들림을 넘어 이동·준비·타격을 구별 |
| P2 | 다층 시차·팔레트·짧은 보스 소개 | 현재 픽셀 스타일을 유지하며 공간감과 분위기 확장 |

P0는 출시 차단 결함 판정이 아니라 **다음 확장 전에 검토할 우선순위**다. 비용은 상대 난도이며 일수·일정 약속이 아니다.

## 이번에 수행한 일과 한계

다섯 연구 묶음의 목록·적용안·한계를 대조하고 현재 장면·판정·UI·스타일·상태 관련 소스를 읽었다. 기존 QA 보고서의 범위도 확인했다. 격리된 메모리 상태에서 자동 장착과 돌진 판정 함수를 실행하고 결과를 저장했다.

새 기능 구현, 사용자 플레이테스트, 새 시각 캡처, 운영 재검증·배포는 수행하지 않았다. 예전 QA 통과는 당시 구현의 증거로만 사용했다. 전체 연구 수를 더해 독립적인 효과 총수로 주장하지 않으며, 같은 목적의 항목은 하나의 적용안으로 통합했다.
