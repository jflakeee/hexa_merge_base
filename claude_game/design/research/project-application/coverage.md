# 전체 연구의 적용 매핑

상태는 이번 소스 검토 범위 기준이다. **기반 있음**은 정확히 같은 효과가 완성됐다는 뜻이 아니며, **추가 후보**는 도입 확정이 아니다. 이 문서에서 B01~B30은 기존 영상 번호에 B를 붙인 참조 표기다. 통합안 R 번호는 [실행안](roadmap.md)을 참조한다.

## 5. 게임 개발 이론의 적용

MDA·동기·의미 있는 선택은 장비 선택과 출전 준비 R02/R07로, 학습 루프는 R07로 연결한다. 경제·확률·성장은 R14, 긴장/휴식은 R15에 연결한다. 게임 루프·상태 머신·저장·이벤트 수명은 R03/R09의 기준으로 활용한다. 플레이테스트·프로토타입·A/B·접근성은 각 단계의 채택 판단에 사용한다.

대규모 A*·행동 트리·ECS·실시간 3D NPR는 현재 문제를 해결하기 위한 필수 도입이 아니다. 이론을 기능 목록으로 바꾸지 않고 각 변경의 목적·가설·검증 기준으로 사용한다.
