# 기존 30종 이후 게임 애니메이션 심층 조사

조사일: 2026-10-05 · 대상: ClaudeGame / Phaser 3.90.0

이번 조사는 **추가 효과 후보 24개, 기존 효과의 확장 8개, 구현 기법 6개**로 나눴다. 이를 서로 독립적인 새 효과 38종이라고 합산하지 않는다. 효과 분류는 산업 표준 목록이 아니라 이 프로젝트의 중복 방지와 개발 판단을 위한 작업 분류다.

- [추가 효과 24개: 원리·적용·중복 경계·출처](research.md)
- [개발 설계: 추천 순서·Phaser 제약·6가지 기법·검증](implementation.md)
- [표 형식 목록 CSV](catalog.csv)
- [기존 영상의 30종 목록](../animation-effects-25olpo56QT4/analysis.md)
- [후속 확장: 화면 전환·카메라·촬영·카툰 렌더링 조사](../cinematic-animation-toon/README.md)

추천 우선순위는 **장비 재배치의 위치 연결 → 2~3층 배경 시차 → 제한된 팔레트 순환 → 보스 시선 추적 → 소품 후속 움직임**이다. 순서는 현재 게임 구조에 대한 판단이며 외부 자료가 이 프로젝트의 우선순위를 실험적으로 입증한 것은 아니다.

공식 엔진 문서, GDC 원본 슬라이드, 기술 저자의 원문, NVIDIA GPU Gems를 조사했다. Phaser 관련 주요 API는 로컬 설치 소스와 3.90.0 문서로 교차 확인했다. 다른 엔진의 문서는 원리 참고용이며 현재 엔진을 교체하자는 제안이 아니다.

이번 작업은 문서 조사다. 추가 효과를 구현·실행 검증하거나 새 영상·에셋을 다운로드하지 않았다. 원본 데모·API의 존재와 우리 게임에서의 성능·시각적 적합성을 구별한다. 기존 게임 코드와 운영 배포는 변경하지 않았다.
