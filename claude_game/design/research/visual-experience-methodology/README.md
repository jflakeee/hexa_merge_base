# 시각 경험 개선을 위한 게임 방법론 딥리서치

조사일: 2026-10-05 · 대상: ClaudeGame / Phaser 기반 2D 픽셀 게임

목표는 **무엇을 보고, 어떤 상태로 이해하고, 어떻게 반응하며, 어떤 분위기를 느끼는지**를 개선하는 것이다. 이번 문서는 효과 목록이 아니라 문제 진단→개선안 비교→실제 장면 검증의 방법론이다.

- [개선 방법론 16개](methods.md): 정보 계층, 실루엣, 배경 정리, 색·형태 문법, 모션, UI, 아트 디렉션 등.
- [검증 프로토콜](evaluation.md): 정지 화면·영상·플레이 관찰·성능 측정의 역할, 측정 정의와 비교 실험.
- [현재 게임 적용안](project-study.md): 기존 스크린샷 2장과 코드 일부에서 확인한 사실, 우선 실험 5개.
- [출처와 한계](sources.md): 공식 제작 자료·접근성 지침·지각 연구·웹 렌더링 자료 10개.
- [개선 실험 기록 양식](experiment-template.csv).

핵심 추천은 **위험 정보의 의미와 표시 일치 → 캐릭터/배경 분리 → 상태·보상 정보 정리 → 모션·픽셀 안정성 → 스타일 확장** 순서다. 우선순위는 현재 프로젝트에 대한 제안이며 효과가 측정된 결론은 아니다.

이번에는 기존 QA 이미지 2장을 직접 열어 관찰하고 `presentation.js`, `arenaLayout.js`의 일부를 읽었다. 새로운 플레이 실행, 사용자 실험, 색 대비 측정, 성능 벤치마크는 수행하지 않았다. 따라서 아래 적용안은 현재 배포본의 시각 검증 완료 보고서가 아니다. 새 게임 코드와 배포는 변경하지 않았다.
