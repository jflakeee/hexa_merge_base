# 게임 개발 이론 딥리서치

조사일: 2026-10-05 · 대상: 게임 개발 전반 및 현재 ClaudeGame의 적용 판단

게임의 품질을 기능 수나 효과 수만으로 평가하기는 어렵다. 이번 조사는 **의도한 경험 → 플레이어의 선택 → 규칙과 자원 흐름 → 구현 → 관찰과 수정**을 연결하는 데 초점을 둔다. 디자인 이론, 심리 연구, 수학적 모델, 엔지니어링 패턴은 근거의 종류가 다르므로 구별한다.

## 핵심 판단

- 효과는 행동의 결과를 이해하게 할 때 가치가 있다. 화려함과 선택의 깊이는 따로 검증한다.
- 선택지는 개수가 아니라 서로 다른 상황에서 선택할 이유가 있는지 확인한다.
- 성장과 희귀 보상은 평균뿐 아니라 분산·장기 미획득·목표 도달 시간을 함께 본다.
- 자동 테스트는 규칙의 정확성을, 영상 검토는 표현의 일관성을, 실제 플레이 관찰은 이해와 경험을 검증한다.
- 기능 추가보다 중요한 불확실성을 먼저 줄인다. 현재 추천 연구 순서는 자동 장착 판단 → 보상 분포 → 첫 성장 학습 → 전투 페이싱이다.

이는 체계적 문헌고찰이나 모든 장르를 포괄한 교과서가 아니라 원문 기반의 실무 연구다. 추천 순서와 예시는 이 프로젝트에 대한 가설이다. 코드 일부를 읽었지만 전체 밸런스·보안·성능 감사를 수행하지 않았으며, 새 기능 구현이나 플레이테스트·배포를 완료했다는 뜻은 아니다.
